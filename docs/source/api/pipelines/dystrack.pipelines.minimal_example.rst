dystrack.pipelines.minimal_example
==================================

A minimal example of a DySTrack image analysis pipeline that simply tracks the 
center of mass of intensity in the image. This is intended as a didactic 
example or as a starting point for customization; for actual center-of-mass 
tracking, we recommend using the more full-featured
:doc:`center-of-mass tracking pipeline</api/pipelines/dystrack.pipelines.center_of_mass>`.
